첨부한 원본 사진을 바탕으로, 원본의 인물·표정·구도·배경은 최대한 유지하면서 감성적인 스크랩북/다이어리 꾸미기 스타일로 편집해줘.

전체 콘셉트는 “오늘의 기록” 같은 사랑스럽고 밝은 SNS 감성이다.
실제 사진 위에 손글씨 메모와 스티커 낙서를 더한 느낌으로,
예쁘고 정돈된 손그림 꾸미기를 적용해줘.

반드시 포함할 요소:

- 상단의 큰 손글씨 메인 타이틀 1개
- 짧은 감성 메모 2\~4개
- 주요 피사체나 소품을 가리키는 손그림 화살표 2\~4개
- 인물 또는 핵심 피사체 주변의 흰색 점선 아웃라인
- 작은 하트, 반짝이, 꽃, 별, 밑줄 등 파스텔 장식 요소
- 오른쪽 아래 또는 빈 공간에 작은 체크리스트 카드 1개

텍스트:

- 메인 타이틀: "cooling sheet"
- 메모: "여름에도 하얀피부", "광밀착 선패치", "꾸안꾸 끝판왕"
- 체크리스트 제목: "여름 썬패치 첵!!"
- 체크리스트:
  1. "얼굴크기 상관없다"
  2. "바른게 티가 안난다
  3. "온도 내려간다"
  4. "자외선 완벽차단"

스타일 규칙:

- 손글씨는 자연스럽고 귀엽게
- 색감은 흰색, 크림색, 연노랑, 연핑크, 연보라, 하늘색 계열의 파스텔 톤
- 핵심 피사체가 가장 먼저 보이고, 장식은 그 다음에 눈에 들어오게 구성
- 텍스트와 장식은 사진 내용을 설명하듯 자연스럽게 배치
- 너무 복잡하거나 과하지 않게, 깔끔하고 완성도 있게 정리
- 실제 사진의 매력을 살린 채, 감성 다이어리처럼 예쁘게 꾸민 결과물로 만들어줘
