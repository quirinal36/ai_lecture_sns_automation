평범한 사진에 손글씨, 스티커, 메모를 더해 나만의 기록처럼 만드는 방법을 알아봅니다.

💡 이 실습의 핵심원본 사진의 분위기를 유지한 채, 다이어리에 붙인 듯한 타이포그래피와 장식 요소를 자연스럽게 추가해 보세요.

예제 3개

실제 실습에 사용한 원본, 완성 이미지, 프롬프트를 한눈에 비교해 보세요.

EXAMPLE 01

여름날 블루베리 피킹

BEFORE
AFTER
사용한 Prompt
전체 프롬프트 보기
원본 사진을 유지한 채, 감성적인 스크랩북/다이어리 꾸미기 스타일로 편집해줘.

컨셉:
- 밝고 사랑스럽고 감성적인 “오늘의 기록” 분위기
- 사진 위에 손글씨 제목, 짧은 메모, 화살표, 점선 아웃라인, 하트, 별, 꽃, 체크리스트 카드 추가
- 실제 사진 + 손그림 낙서가 자연스럽게 섞인 스타일
- 인물과 배경은 최대한 유지하고, 장식은 사진을 더 예쁘게 보이게 하는 수준으로만 추가

반드시 포함할 요소:
- 큰 메인 타이틀: "Blueberry picking day"
- 짧은 메모 3개: "sunny day", "fresh berries", "today's harvest"
- 체크리스트 카드 제목: "오늘의 블루베리"
- 체크리스트 4개: "잘 익은 열매 찾기", "조심조심 수확하기", "바구니 가득 채우기", "한 알 맛보기"

디자인 규칙:
- 제목은 상단의 깨끗한 공간에 크게
- 핵심 피사체 주변은 흰색 점선 아웃라인
- 주요 소품/오브젝트에는 손그림 화살표와 작은 메모 추가
- 오른쪽 아래 또는 빈 공간에 작은 체크리스트 카드 배치
- 작은 하트, 꽃, 별, 반짝이, 밑줄 등으로 포인트 추가
- 색상은 흰색, 크림색, 연노랑, 연핑크, 연보라, 하늘색 계열의 파스텔 톤
- 글씨는 귀엽고 자연스러운 손글씨 느낌
- 전체적으로 과하지 않게, 완성도 있는 SNS 감성 편집처럼

중요:
- 원본 인물의 얼굴, 포즈, 의상, 소품은 유지
- 원본 사진의 주제와 분위기를 해치지 말 것
- 사진보다 장식이 더 튀지 않도록 균형 있게 구성
EXAMPLE 02

여름 쿨링 선패치

BEFORE
AFTER
사용한 Prompt
전체 프롬프트 보기
첨부한 원본 사진을 바탕으로, 원본의 인물·표정·구도·배경은 최대한 유지하면서 감성적인 스크랩북/다이어리 꾸미기 스타일로 편집해줘.

전체 콘셉트는 “오늘의 기록” 같은 사랑스럽고 밝은 SNS 감성이다.
실제 사진 위에 손글씨 메모와 스티커 낙서를 더한 느낌으로, 예쁘고 정돈된 손그림 꾸미기를 적용해줘.

반드시 포함할 요소:
- 상단의 큰 손글씨 메인 타이틀 1개
- 짧은 감성 메모 2~4개
- 주요 피사체나 소품을 가리키는 손그림 화살표 2~4개
- 인물 또는 핵심 피사체 주변의 흰색 점선 아웃라인
- 작은 하트, 반짝이, 꽃, 별, 밑줄 등 파스텔 장식 요소
- 오른쪽 아래 또는 빈 공간에 작은 체크리스트 카드 1개

텍스트:
- 메인 타이틀: "cooling sheet"
- 메모: "여름에도 하얀피부", "광밀착 선패치", "꾸안꾸 끝판왕"
- 체크리스트 제목: "여름 썬패치 첵!!"
- 체크리스트: "얼굴크기 상관없다", "바른게 티가 안난다", "온도 내려간다", "자외선 완벽차단"

스타일 규칙:
- 손글씨는 자연스럽고 귀엽게
- 색감은 흰색, 크림색, 연노랑, 연핑크, 연보라, 하늘색 계열의 파스텔 톤
- 핵심 피사체가 가장 먼저 보이고, 장식은 그 다음에 눈에 들어오게 구성
- 텍스트와 장식은 사진 내용을 설명하듯 자연스럽게 배치
- 너무 복잡하거나 과하지 않게, 깔끔하고 완성도 있게 정리
- 실제 사진의 매력을 살린 채, 감성 다이어리처럼 예쁘게 꾸민 결과물로 만들어줘
EXAMPLE 03

tiny coffee break

BEFORE
AFTER
사용한 Prompt
전체 프롬프트 보기
첨부한 원본 사진을 바탕으로, 원본의 인물·표정·구도·배경은 최대한 유지하면서 감성적인 스크랩북/다이어리 꾸미기 스타일로 편집해줘.
전체 콘셉트는 “작은 나만의 카페에서 보내는 오늘의 커피 브레이크” 같은 사랑스럽고 밝은 SNS 감성이다.
실제 사진 위에 손글씨 메모와 스티커 낙서를 더한 느낌으로, 예쁘고 정돈된 손그림 꾸미기를 적용해줘.

- 상단의 큰 손글씨 메인 타이틀 1개
- 짧은 감성 메모 2~4개
- 주요 피사체나 소품을 가리키는 손그림 화살표 2~4개
- 인물 또는 핵심 피사체 주변의 흰색 점선 아웃라인
- 작은 하트, 반짝이, 꽃, 별, 밑줄 등 파스텔 장식 요소
- 오른쪽 아래 또는 빈 공간에 작은 체크리스트 카드 1개

텍스트:
- 메인 타이틀: "tiny coffee break"
- 메모: "한 모금 쉬어가기", "작지만 완벽한 카페", "코딩하다 커피타임"
- 체크리스트 제목: "오늘의 미니카페 첵!!"
- 체크리스트: "따뜻한 커피 준비", "좋아하는 자리에 앉기", "잠깐 여유 즐기기", "다시 즐겁게 시작!"

텍스트 배치:
- "tiny coffee break"는 사진 상단의 비교적 비어 있는 공간에 크게 배치
- "한 모금 쉬어가기"는 인물이 들고 있는 커피잔 근처에 배치하고 손그림 화살표로 컵을 가리키기
- "작지만 완벽한 카페"는 미니어처 공간 전체 또는 네온사인 근처에 배치
- "코딩하다 커피타임"은 모니터나 책상 주변에 배치하고 작은 화살표로 컴퓨터를 가리키기
- 체크리스트 카드는 오른쪽 아래나 바닥 쪽 빈 공간에 작은 메모지처럼 붙여놓기

스타일 규칙:
- 손글씨는 자연스럽고 귀엽게
- 색감은 흰색, 크림색, 연노랑, 연핑크, 연보라, 하늘색 계열의 파스텔 톤
- 기존 사진의 네온 핑크·청록 조명과 자연스럽게 어울리도록 파스텔 색상을 조절
- 핵심 피사체인 커피를 마시는 인물과 미니 카페 공간이 가장 먼저 보이도록 구성
- 인물과 미니 카페 입구 주변에는 흰색 점선 아웃라인을 가볍게 적용
- 커피잔, 모니터, 네온사인 주변에 작은 하트, 별, 반짝이, 밑줄 장식을 추가
- 텍스트와 장식은 사진 내용을 설명하듯 자연스럽게 배치
- 너무 복잡하거나 과하지 않게, 여백을 충분히 남겨 깔끔하고 완성도 있게 정리
- 실제 사진의 입체감과 미니어처 디오라마 특유의 매력을 유지
- 전체적으로 미니어처 세계에서 보낸 하루를 다이어리에 기록한 듯한 결과물로 만들어줘.
