# PULSE — 10초 앱 홍보

PULSE는 일상 속 아이디어와 영감을 모으는 가상의 앱입니다. “일상을, 내 리듬으로.”라는 한 문장을 스마트폰의 움직임으로 보여줍니다.

## 연출 방향

참고 영상: https://www.youtube.com/shorts/JruzJjQONJI

aside CLI로 원본의 0, 1.5, 3, 4.5, 6, 9, 10.5, 12, 15초 화면을 확인했습니다. 원본은 16.101초, 720×720입니다. 참고한 요소는 스마트폰의 회전과 확대, 여러 스마트폰으로 확장되는 배열, 큰 글자, 밝은 배경에서 어두운 엔딩으로의 전환입니다. 원본의 제품 영상·로고·성과 수치는 사용하지 않습니다.

## 10초 구성

| 구간 | 내용 | 움직임의 목적 |
|---|---|---|
| 도입 | PULSE 앱 화면이 담긴 스마트폰 등장 | 첫 순간에 제품과 색상을 인식 |
| 접근 | 스마트폰이 앞으로 다가오며 각도 변화 | 화면 속 콘텐츠에 시선 집중 |
| 확장 | 한 대에서 여러 스마트폰 화면으로 확장 | 다양한 일상을 하나의 앱에 담는다는 인상 |
| 마무리 | 어두운 배경에 PULSE와 한 문장 | 브랜드 이름이 기억되도록 읽을 시간 확보 |

## 제작 기준

- 1080×1080, 30fps, 10초.
- 흰색에 가까운 따뜻한 배경, 검은 기기, 코럴 강조색.
- 한국어 문구는 짧고 크게 배치.
- 원본 브랜드나 실제 앱의 성과를 주장하지 않는 데모.
- HTML/CSS/GSAP 기반으로 텍스트·색상·기기 화면을 수정할 수 있는 HyperFrames 프로젝트.
- 내레이션 없이 화면 움직임을 중심으로 구성.
