첨부한 원본 사진을 바탕으로, 원본의 인물·표정·구도·배경은 최대한 유지하면서 감성적인 스크랩북/다이어리 꾸미기 스타일로 편집해줘.
전체 콘셉트는 “작은 나만의 카페에서 보내는 오늘의 커피 브레이크” 같은 사랑스럽고 밝은 SNS 감성이다.
실제 사진 위에 손글씨 메모와 스티커 낙서를 더한 느낌으로,
예쁘고 정돈된 손그림 꾸미기를 적용해줘.
반드시 포함할 요소:
- 상단의 큰 손글씨 메인 타이틀 1개
- 짧은 감성 메모 2~4개
- 주요 피사체나 소품을 가리키는 손그림 화살표 2~4개
- 인물 또는 핵심 피사체 주변의 흰색 점선 아웃라인
- 작은 하트, 반짝이, 꽃, 별, 밑줄 등 파스텔 장식 요소
- 오른쪽 아래 또는 빈 공간에 작은 체크리스트 카드 1개
텍스트:
- 메인 타이틀: "tiny coffee break"
- 메모:
  - "한 모금 쉬어가기"
  - "작지만 완벽한 카페"
  - "코딩하다 커피타임"
- 체크리스트 제목: "오늘의 미니카페 첵!!"
- 체크리스트:
  1. "따뜻한 커피 준비"
  2. "좋아하는 자리에 앉기"
  3. "잠깐 여유 즐기기"
  4. "다시 즐겁게 시작!"
텍스트 배치:
- **"tiny coffee break"**는 사진 상단의 비교적 비어 있는 공간에 크게 배치
- **"한 모금 쉬어가기"**는 인물이 들고 있는 커피잔 근처에 배치하고 손그림 화살표로 컵을 가리키기
- **"작지만 완벽한 카페"**는 미니어처 공간 전체 또는 네온사인 근처에 배치
- **"코딩하다 커피타임"**은 모니터나 책상 주변에 배치하고 작은 화살표로 컴퓨터를 가리키기
- 체크리스트 카드는 오른쪽 아래나 바닥 쪽 빈 공간에 작은 메모지처럼 붙여놓기
스타일 규칙:
- 손글씨는 자연스럽고 귀엽게
- 색감은 흰색, 크림색, 연노랑, 연핑크, 연보라, 하늘색 계열의 파스텔 톤
- 기존 사진의 네온 핑크·청록 조명과 자연스럽게 어울리도록 파스텔 색상을 조절
- 핵심 피사체인 커피를 마시는 인물과 미니 카페 공간이 가장 먼저 보이도록 구성
- 인물과 미니 카페 입구 주변에는 흰색 점선 아웃라인을 가볍게 적용
- 커피잔, 모니터, 네온사인 주변에 작은 하트, 별, 반짝이, 밑줄 장식을 추가
- 텍스트와 장식은 사진 내용을 설명하듯 자연스럽게 배치
- 너무 복잡하거나 과하지 않게, 여백을 충분히 남겨 깔끔하고 완성도 있게 정리
- 실제 사진의 입체감과 미니어처 디오라마 특유의 매력을 유지
- 전체적으로 미니어처 세계에서 보낸 하루를 다이어리에 기록한 듯한 결과물로 만들어줘.
